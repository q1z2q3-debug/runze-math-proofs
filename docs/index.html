摘要

本仓库记录 TCSExam 开放猜想的形式化实验。当前重点是 bin-packing 的 Modified Integer Round-Up Property：在 instC 上给出 Lean core 可检查的证书，并用 39,150 个实例搜索反例。结论只写到证据允许的边界：算术已核，ℝ/ℚ 桥接仍需完整 mathlib 环境。

核心结构

  • lean/：Lean 4 工程；scripts/：精确装箱、证书生成、反例搜索；data/：证书与日志。
  • docs/：忠实性核查、文献前沿、屏障分析与 19683 认知格映射。
  • 所有数字都能由 scripts/ 复跑；不能复跑的部分明确标注环境限制。

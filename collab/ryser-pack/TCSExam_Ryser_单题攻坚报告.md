## 三、定理 A（归约，可证，实例无关）

设 `H` 是 `r`-部 `r`-一致超图，`D ∈ ℕ`。若

1. **相交**：任意两条不同边在某个部取同一顶点；

2. **互异**：边表中无重复横截（否则 `Finset` 会合并，`|E|` 变小）；

3. **度约束**：每个顶点 `(p,v)` 至多属于 `D` 条边；

4. **规模**：`|E| > (r−1)·D`；


则 `¬ H.RyserBound`，即 `refuted` 成立。

**证明**：由 (1)，任何两条边共享顶点，故匹配至多含一条边，且 `|E|≥2` ⇒ `ν(H)=1`。任取顶点覆盖 `C`：每条边至少被 `C` 中一个顶点击中，而每个顶点最多在 `D` 条边中，于是 `|E| ≤ |C|·D`，即 `|C| ≥ ⌈|E|/D⌉`。由 (4) 得 `⌈|E|/D⌉ ≥ r`，故 `τ(H) ≥ r`。而 `RyserBound` 要求 `τ ≤ (r−1)·ν = r−1`，矛盾。∎

这条定理把「证伪 Ryser」从**指数级覆盖枚举**压成了**度数 + 计数**，Lean 里用官方 `le_coverNumber` / `matchingNumber_le` 两个 API 引理即可搭起来，所有有限侧条件都可以 `by decide` 检查（官方 `small-examples.md` 已确认 `decide` 在此定义层 axiom 清洁）。

## 四、定理 B（障碍，可证，本轮最实的东西）

若 `H` 满足定理 A 的 (1)(3)，`|E|=(r−1)D+k`（`1≤k<D`），则

```
C(|E|,2)  ≤  r · [ ⌊|E|/D⌋·C(D,2) + C(|E| mod D, 2) ]
```

**证明**：每一对边必须至少在某个部同值（相交）。部 `p` 中值 `v` 的度记为 `d_{p,v}`，该部贡献的同值边对数是 `Σ_v C(d_{p,v},2)`。所有 `C(|E|,2)` 个边对都要被某个部的同值关系覆盖（允许重复），故 LHS ≤ 各部贡献之和。又 `Σ_v d_{p,v}=|E|` 且 `d_{p,v} ≤ D`，凸性给出 `Σ_v C(d,2)` 在度尽量堆到 `D` 时最大，即 `⌊|E|/D⌋·C(D,2)+C(|E| mod D,2)`。∎

取最小规模 `k=1`，两边相减化简得到一个干净的下界：

```
LHS − RHS = (r−1)·D·(r+1−D) / 2     ⇒     必须 D ≥ r+1
```

**推论**：任何「度约束型」Ryser 反例必须 `D ≥ r+1`，且 `|E| ≥ (r−1)(r+1)+1 = r²`。具体：

| r | 最小 D | 最小 \|E\| | 每部至少顶点数 |
|---|---|---|---|

| 6 | 7 | 36 | ≥7 |
| 7 | 8 | 49 | ≥8 |
| 8 | 9 | 64 | ≥9 |
| 9 | 10 | 81 | ≥10 |

这解释了三件事：

- 前面试过的 `r=6, D=3..6` 全部在计数层面就**严格不可能**，不是搜索不够努力；

- 截断射影平面永远 `|E|=(r−1)D` 恰好紧，加一条边就立刻撞上度约束；

- 已发表反例必须来自「充分大的 q」——构造规模至少 `r²` 条边、每部 `~r` 个顶点 [citation:1][citation:8]。
